# mtc-solo

作者：苏勃(subo)

许可：Apache-2.0，全文见仓库根目录 `LICENSE`。仓库仍先私有。公开时这份许可证随仓库分发。

不对接充电桩的电摩充电机，在 `mtc-link` 之上的出流和超时判定。

本仓先私有。与 `mtc-link`、`mtc-dock` 一起稳定后再公开。公开文本不出现公司、客户、供应商、价格、具体料号和具体机型。

## 用途

给只从市电或本机直流母线取电、不向充电桩交换数据的充电机一份符合性。实现者依赖 `mtc-link` 的报文、口、明文、加密和电气匹配，不在这里重写帧。本仓只回答两件事：电流按哪一条报文出，以及请求中断多久后输出必须已经是 0。

一台机器只符合 `mtc-solo` 或 `mtc-dock` 其中一份。

## 本仓包含

- 出流只跟随 `0x01`。允许、暂停、停止、请求电压和请求电流都以这条报文为准。
- `0x04` 不把电流往上加。电气匹配失败时，输出电流为 0。匹配成功也不提高 `0x01` 已经给出的电流。
- 满 1 秒没有合法 `0x01`，输出已经是 0。不使用 1.2 秒窗口。
- 停止、暂停、允许位清除或请求电流为 0 时，输出回到 0。没有合法请求时不得改成盲充。
- `0x03` 里表示交流路径、直流路径的位必须为 0。
- 目录里记录所依赖的 `mtc-link` 版本。该版本的报文测试通过之后，才改这个版本号。

## 本仓不包含

- 不写帧壳、CRC、三种口和加密套件。那是 `mtc-link`。
- 不把电池电压、电流、荷电和允许值交给桩侧。对接充电桩的交出条件是 `mtc-dock`。
- 不写暂停后第一拍的电流斜率和电压回退。
- 不写 `0x04` 超过 3 秒则禁止桩侧能量传输。不对接充电桩的机器没有这条限制。
- 不写倍率表、仪表帧、桩报文和具体硬件。

## 依赖

只依赖 `mtc-link`。不依赖 `mtc-dock`、`mtc-strategy`、`mtc-meter`、`mtc-pile-sim` 和 `mtc-crypt`。

## 出流剖面

本仓是家充剖面。满 1 秒没有合法 `0x01`，输出已经是 0。

`mtc-link` 的参考实现是链路剖面：不满 1 秒不停，到 1.2 秒输出为 0。对接充电桩的交接是 `mtc-dock`。三个仓以后公开时用同一组版本号。版本号这次还不打。两个剖面不混用，也不并成一条超时。

## 现状

判定写在 `doc/conformance.md`。`mtc-link` 里现有参考实现仍是不满 1 秒不停、到 1.2 秒输出为 0。不对接充电桩的符合性以本仓正文为准。
